# D8 — Há 4 views, e cada uma é um padrão de representação de dados *(decisão)*

- Data: 2026-11-03
- Estado: decidido

## Contexto
O protótipo tem 4 views (destaque com grelha, lista, mural, indicadores) sem significado definido.

## Opções
1. As views como temas (por exemplo, dia, trabalho, saúde).
2. As views como padrões de representação de dados, que servem qualquer tema.
3. Views configuráveis pelo utilizador.

## Decisão
Opção 2, com 4 views fixas:
1. **Destaque**: o que importa agora, um elemento grande e alguns pequenos;
2. **Lista**: itens em sequência;
3. **Mural**: conteúdo visual, com alturas variáveis;
4. **Indicadores**: números e tendências.

## Porquê
O propósito é "formas simples de representar dados". Os padrões não dependem do conteúdo e servem tanto para a vida pessoal como para o trabalho.

## Consequências
- O conteúdo concreto de cada view define-se na fase 4.
- Views configuráveis ficam fora da v2.
- O design system da fase 3 documenta os 4 padrões como componentes.
