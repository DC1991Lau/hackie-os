# Brand

Identidade visual e verbal da Hackie.

Por preencher:

- `logo/` — variantes, formatos, regras de utilização
- `colors.md` — paleta (o documento fundacional usa `#0D2535` primary, `#00897B` accent, `#F7F5F2` background)
- `typography.md` — Fraunces (display) + Inter (body), conforme o documento fundacional
- `assets/` — imagens, ícones, templates gráficos

O **tom de voz** não vive aqui — vive na skill `.claude/skills/hackie-voice/`, para que o Claude o carregue automaticamente ao escrever.
