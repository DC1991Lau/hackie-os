# Brand

Identidade visual e verbal da Hackie. **Fonte da verdade** — o documento fundacional
e o website derivam daqui, não o contrário.

| Ficheiro | O que define | Estado |
|---|---|---|
| `colors.md` | Paleta e regras de utilização | ✅ |
| `typography.md` | Famílias, escala e regras | ✅ |
| `logo/` | Variantes, formatos, regras de utilização | ⬜ |
| `assets/` | Imagens, ícones, templates gráficos | ⬜ |

O **tom de voz** não vive aqui — vive na skill `.claude/skills/hackie-voice/`, para
que o Claude o carregue automaticamente ao escrever.
