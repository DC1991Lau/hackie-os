# Hackie voice

Source of truth: `00-core/foundation/manifesto.md` and `00-core/foundation/vision-mission-values.md`.
This skill describes *how* Hackie writes. Read those files for *what* it believes.

## Language

European Portuguese. Second person singular — **tu**, not "você" and not "o cliente".
Product vocabulary stays English and unchanged: Pulse, Studio, Partner, Experience, Growth, Efficiency, Education, AI-Native, Web Experience, Custom Platforms, AI Assistants, AI Agents.

## Rhythm

Short declarative sentences. One idea per line. Paragraphs of one to three lines.
Build with triads, especially negative ones — the manifesto's core move:

> Não entregamos e desaparecemos. Não vendemos horas. Não criamos dependências.

Then resolve on a positive:

> Construímos sistemas que libertam.

Em-dash for the turn in a sentence. Never a semicolon.

## The recurring frame

Almost every Hackie argument has the same shape:

1. The client already has what matters (product, experience, care).
2. What blocks them is not talent — it is access, noise, fragmentation.
3. Technology is infrastructure, not privilege. AI is the leveller.
4. We build, we transfer the knowledge, we leave them able to operate it alone.

Use it. Do not restate all four every time.

## Vocabulary

**Use:** ruído · sistemas · acesso · soberania · autonomia · transferência de conhecimento · sem lock-in · parceria · clareza · infraestrutura

**Avoid:** disruptivo · revolucionário · inovador · soluções à medida (empty) · sinergia · potenciar · alavancar · "líder de mercado" · exclamation marks · emoji

## Hard rules

- **Never promise a team.** Hackie is one person by design. Say "leve", "sem overhead", "sem camadas entre o cliente e o trabalho" — never "a nossa equipa".
- **Never sell hours.** Price reflects value delivered. See `00-core/offering/pricing.md`.
- **Never claim a case study that does not exist.** The practice is in the *Entrada* phase — no portfolio yet. Say what you will do, not what you have done.
- **Never overstate AI.** It is a tool for removing complexity, not a selling point on its own.
- **Do not create dependency in the copy.** If a sentence implies the client will always need Hackie, rewrite it.
